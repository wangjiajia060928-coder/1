# EAT 页面

这是可直接部署到 GitHub Pages 的静态网页文件。

## 文件说明

- `index.html`：网站入口
- `frame-14.svg`：首页
- `group-10.svg`：左侧选中状态
- `right-selected.svg`：右侧选中状态
- `result.svg`：结果页
- `retry.svg`：重选页
- `share.svg`：分享页

## GitHub Pages 部署

1. 新建 GitHub 仓库。
2. 将本目录内的全部文件上传至仓库根目录。
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和根目录 `/ (root)`，点击保存。

部署完成后，GitHub 会显示网站访问地址。
